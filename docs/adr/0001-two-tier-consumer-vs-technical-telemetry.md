# Two-Tier Separation of Consumer UI Copy and Deep Psychometric Telemetry

Consumer-facing UI components must exclusively use empathetic, non-stigmatizing terms ('Your Thinking Style', '✨ Why Brian Suggests This', 'Weekly Progress Boost') while academic and mathematical telemetry ('SAT-JEPA', 'QUEST+', 'Epistemic Uncertainty ±1.96σ', '5-Part Reasoning Trail') is encapsulated in collapsible `<details>` drawers ('Explore How This Is Calculated') and deep telemetry tabs. This prevents stereotype threat and cognitive fatigue in learners while maintaining rigorous, auditable scientific grounding for AI competition rubrics.
