# Two-Tier Separation of Consumer UI Copy and Deep Psychometric Telemetry

Consumer-facing screens use only plain, non-stigmatizing words from [the glossary](../GLOSSARY.md) (the 5 skills, "Why Loti picked this", "Not measured yet"). Technical and mathematical detail (d′, Stroop cost, SAT-JEPA, reliable-change gates, the pillar weights) lives in one place: "How we calculate this" (`/methodology`), in closed topics. This prevents stereotype threat and overload for learners, while keeping the method auditable for evaluators.

*Updated 2026-10-31: the examples now use brand v2 words. The earlier examples ("Why Brian Suggests This", "Weekly Progress Boost", "Epistemic Uncertainty ±1.96σ" drawers on every screen) are retired.*
